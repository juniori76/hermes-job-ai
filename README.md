# Hermes Job AI 🤖🏹
> Sistema autônomo inteligente de caça e candidatura automática a vagas de emprego, com inteligência artificial para quebra de filtros ATS e operação 24/7.

## 📌 Arquitetura e Funcionalidades
- **Radar Multi-Plataforma:** Coleta contínua em LinkedIn, Gupy, Indeed e Glassdoor.
- **ATS-Breaker (LLM Brain):** Otimização de palavras-chave e respostas técnicas convincentes (método STAR).
- **Filtro Geográfico Inteligente:** Seleção de vagas remotas ou híbridas respeitando o raio de distância ideal.
- **Dashboard Web HTTP:** Acompanhe métricas, ranking das melhores vagas e aprove candidaturas pelo celular/PC.
- **Operação 24/7 em Docker:** Isolado e leve para servidores Linux domésticos.
