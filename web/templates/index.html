Notificações via Telegram Não configurado

Configure seu Bot do Telegram para receber alertas de vagas com score alto diretamente no celular. No modo Inteligente o Hermes envia alertas. No modo Automático ele também se candidata.

Como múltiplos usuários utilizam o mesmo Bot do Telegram:

  • Você só precisa criar 1 único Bot no Telegram (pelo @BotFather) e colar o Token abaixo.
  • Cada usuário abre a conversa com o bot no celular e digita: /vincular seu_usuario (ex: /vincular gabriel). O Hermes passa a enviar alertas individuais e direcionados.
  • O bot vincula na hora e só manda as vagas da área daquela pessoa para o celular dela!

📌 Como obter:

1. Fale com @BotFather no Telegram → /newbot → copie o Token

2. Fale com @userinfobot no Telegram → copie seu Chat ID
